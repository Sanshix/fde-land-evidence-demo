# 开源视觉推理模型选型与后台切换

2026-10-29 核对阿里云百炼深度思考、视觉理解文档及 Qwen 官方模型卡。此前默认链路按单页 OCR 耗时排序，不代表合同理解能力排序。本次新增七个可本地部署的 Qwen 候选，保留原部署配置作为可恢复基线。

| 档位 | 模型 | 纯权重 BF16 / INT4 理论值（GB） | 选型理由 |
|---|---|---:|---|
| 优先评测 | Qwen3.8-27B | 54 / 13.5 | 新一代视觉推理，优先验证质量与部署成本 |
| 高算力对照 | Qwen3.5-397B-A17B | 794 / 198.5 | 大模型对照，需要多卡；激活17B不等于只存17B |
| 高能力 | Qwen3.5-122B-A10B | 244 / 61 | 多卡均衡候选 |
| 均衡 | Qwen3.6-35B-A3B | 70 / 17.5 | 较低计算量，吞吐优先候选 |
| 标准对照 | Qwen3.5-27B | 54 / 13.5 | 同规模旧版对照 |
| 经济基线 | Qwen3.5-35B-A3B | 70 / 17.5 | 旧版 MoE 基线 |
| 轻量 | Qwen3-VL-8B-Thinking | 16 / 4 | 低资源视觉推理基线 |

这些数字仅按参数量×位宽估算，不是可运行显存配置；尚未计入视觉编码器、KV/cache、量化元数据、运行时及并发。不同代际、稠密与MoE之间不存在已验证的严格能力全序，列表表示评测优先级与部署档位，不是假造的合同准确率排行榜。官方基准与本项目效果需分别记录。

当前识别路径直接输入扫描图片，因此候选必须具备视觉能力。纯文本推理模型应通过另一个“已提取原文＋来源引用”的阶段接入，不能直接替换图片接口。Qwen3.8-2.4T-A95B 未纳入当前视觉直读目录；商业 Max/Plus、现有 qwen-vl-ocr 服务也不作为已确认开放权重候选。

## 后台操作

以管理员进入「系统管理 → 模型选择」，加载配置，选择模型与本地/阿里云 API，明确是否启用，然后保存。此入口切换调用配置，不负责下载权重或启动推理服务。

本地模式需先提供 OpenAI Chat Completions 兼容的视觉服务（例如 vLLM），模型服务名须与目录的 `Qwen/...` ID 一致；混合思考通过 `chat_template_kwargs.enable_thinking` 开启，需要部署兼容的模板和推理解析器。本地界面只接受回环或RFC1918内网IP，内部域名及带认证服务仍由运维在部署文件中配置后恢复原配置使用。

阿里云模式复用部署文件已有、获授权的阿里云地址和密钥变量，保留原材料外发授权范围，不从前端输入或返回密钥。各地域模型可用性须以实际账号验证，目录收录不等于当前账号已开通。

保存使用数据库事务、版本冲突检查与审计；不改写配置文件。部署文件变化使已有选择失效，避免带着旧授权覆盖新部署。运行中任务/已持久化后备任务沿用原配置，下一次开始的任务读取新选择；已识别历史结果不自动重算。恢复按钮恢复部署文件的整条链路和启用状态。

选择新模型后仅启用主路径，原后备链路被替换，避免内网失败转公网，也不把同一模型当作独立第二证据。保持人工确认门槛及规则核算。

## 推理协议与验证边界

新候选使用 SSE 流式调用，区分最终 `content` 与 `reasoning_content`，不把思维过程写成合同字段。流中错误、超时、缺少完成标记、长度截断均不可采纳为完整识别。思考预算4096、输出上限12000；保留既有整体任务预算，较慢模型可能超时，需实际测量后调度，不能据此承诺20分钟整包完成。缓存签名包含思考参数。

本轮工程测试使用隔离数据库和 HTTP mock；没有执行真实模型准确率测试，没有下载权重或变更当前业务库设置。后续比较同一批样本的关键字段全对率、证据引用正确率、涂改漏报率、无法判断保留率、P50/P95耗时及每份成本，再确定生产默认模型。不得只按数学榜单或参数量定默认。
