# 工作台八项业务改造与验收

2026-10-28。实施基线为本次开始时已存在的未提交工作区，未重置既有修改、未提交或推送。

## 功能与入口

主菜单按需求表2依次为：存量合同治理、一宗一档电子台账、租金核算、到期与欠缴提醒、催缴通知、合同生成与续期变更、税务推送单、统计查询。系统管理独立保留。旧 inbox/governance/review/ledger/measure hash 入口兼容。

- 治理：材料管理、待核验、核对详情使用页内导航，继续复用原件证据、补件、撤回、重导与确认门禁。
- 台账：20宗分页、按宗展开详情，查询历史快照、原件及合同链。统计、提醒、税务全局操作移至各自页面。
- 核算：逐年分段、实缴分配、减免、存疑算法与差额；补录缴费必须选择已上传的凭证、填写核验依据，先预览再确认。票据在原始来源或补录记录中已出现时拒绝重复入账。
- 规则：费率业务表单，受控政策版本；当前支持自然月分段、批准来源减免、最低应缴暂算两种舍入选择。未实现的日分段等策略由后端拒绝。修改必须经管理员逐宗差异预览与复核。历史通知与核算版本不修改。
- 提醒：查看日期独立于金额核算日期；30天橙色、31–90天黄色、已到期红色；欠缴1–2年度橙色、3年度以上红色。列表、月历、ICS导出及宗地/续期/催缴跳转。
- 合同：新宗地或既有宗地可起草新签；已有宗地可起草续期。合同列表可查看、下载。草稿不创建生效宗地或应收。变更协议进入原有证据核验流程；终止需要依据、终止日期、差异预览及确认，历史欠缴保留。
- 催缴：草稿、人工审核、持久化发送任务、结果和回执分别保留；重复发送请求复用原任务，超时为结果未知。模拟回执重复不重复入账，冲突回执拒绝。人工登记缴清不改变金额，实际缴费确认后才重算。
- 税务：清单内容预览、确认归档、历史下载、来源指纹及文件哈希留存。归档时再次检查来源变化。旧生成接口兼容历史调用；新工作台始终携带预览指纹。
- 统计：街路、状态、欠缴、关键字筛选与CSV使用同一口径，展示分母分子、多缴说明和对应宗地查询入口。

## 接口与数据

新增 `app/workbench.py` 注册合同列表/详情、宗地历史、业务事件预览/确认、短信任务/模拟回执接口。`app/static/business.js` 负责业务页面加载，复用现有样式、表格和弹窗。

新增 business_events、sms_tasks、sms_receipts、output_provenance 表；业务确认事件、回执和输出依据不可修改。规则表兼容旧费率数组与新版费率/政策对象。原有表和导出格式保留。

短信适配器约定见 `app/sms.py`：`FDE_SMS_ADAPTER=package.module:factory`。适配器接收 task_id、phone、text，必须将 task_id 用作通道幂等键。未配置真实适配器时拒绝真实发送。工作台的发送按钮均明确为模拟操作。
