# 比赛闭环修复与验收

本轮目标是修复识别覆盖、人工接管和批量准入之间的断点。远端报告原始日志不在本机，22.71 分及根因分摊未经复现，不作为本次修复结果。

## 已实现

- 多页请求使用请求内整数页号，由服务端映射真实证据 ID；只兼容完全一致的历史 ID。越界、跨页冲突引用隔离对应候选，不猜测修复。
- 主请求失败保留尝试记录及无效响应，继续有界的逐页识别。成功页面与路径缓存复用；缓存包含完整 endpoint、图片摘要、提示版本，字段顺序固定，重启不会因为哈希顺序不同而重发。
- 沿用两个持久任务队列：主队列完成首轮便继续下一份材料；后备队列按配置顺序识别。单进程实际请求最多 2 个；文档总预算 240 秒，主阶段最多 120 秒，后备等待也消耗原预算。此上限不等于多进程部署的全局限流。
- 结果区分 completed / partial / unknown / failed，并逐页列出读取覆盖。completed 仅说明读取协议结束；失败页面不能因为其他页字段齐全而跳过。超时不自动重发；百度已知任务号保留。用户显式重发未知请求须填写依据，仍在执行的同一请求不重复发送。
- 缺置信度保存为空值；兼容历史 `score=0, score_meaning=not_provided`。有效主证据可以配合无框辅助文字佐证；真实低分、实际冲突、无主证据和单一路径仍转人工。模型自报分数不是正确概率。
- 比较值做确定性格式规范，原文保留。变更协议按文档类型校验。未提供坐标不能伪装原生结构引用；布尔值也不能当坐标。
- 待核验列表优先处理可补齐当前已知宗地材料链的材料，再按问题复杂度排序；分组仅依赖已采纳或唯一候选宗地号，不知道未导入原件是否存在。
- 涂改复核展示真实候选区域和完整原件；没有签章区域则明确缺少定位。真人显式选择有签章、无签章或无法判断。未知保持挂起；挂起后可直接继续人工核验，草稿保留，不要求重新付费识别。签章决定及依据页绑定租金预览和发布审计。
- 导出继续根据真实确认方式填写处理方式。不会通过修改 CSV 标签取得自动通过分数。缴费唯一归属、弱匹配转人工、四舍五入默认口径及历史发布保护继续生效。

## 真实调用暴露的适配问题

首轮真实小样本中，原阿里通用中文 OCR 提示多次只得到坐标数字；接口响应快不能说明完成了文字识别。按[阿里官方 OCR 任务说明](https://help.aliyun.com/zh/model-studio/qwen-vl-ocr)调整兼容接口的任务提示和图文顺序；纯坐标响应现在显式失败并保留原始证据。

百度返回的版面块和 HTML 表格此前被当作普通标签文本，无法恢复多数合同字段。本轮新增版面/表格适配器，保留同格多值，只有返回坐标系、尺寸和未旋转条件可验证时才映射整块区域；布局分数不冒充文字正确率。结构化补读使用完整字段集合，避免仅补必填项而漏掉合同编号、签订日期和证件号码。

## 可复现入口

仅真实模拟材料识别（独立数据库、原配置开关不变）：

```sh
.venv/bin/python scripts/competition_run.py --samples ../练习集 --run runs/competition-exercise --live
.venv/bin/python scripts/competition_run.py --samples ../评测集 --run runs/competition-evaluation --live
```

恢复同一运行加 `--resume` 并保持材料、文档筛选一致。成功证据复用，失败/未知任务不会因此偷偷重新排队；通过工作台明确恢复。工具不代替人确认。

实际导出的 CSV 或 ZIP 离线计分：

```sh
.venv/bin/python scripts/score_submission.py --answers ../练习集/08_标准答案 --submission /实际导出.zip --output runs/score-current
```

可加 `--scenario recovery=/另一次实际导出目录` 对比；组合情景用 `--scenario recovery+review=/实际组合导出目录`。只计算实际文件间差异和交互，不能据此宣称因果失分百分比。独立评测集没有答案，不能生成准确率或官方得分。

## 验收边界

自动通过的计分必要条件是整份关键字段正确率大于 75%，不是逐字段平均准确率。验证集内出现已知错误自动放行就需要修正路由；没有观察到错误不代表风险为零。精度、发布覆盖、已发布子集指标及人工净工时必须分别记录。

真实签章判断、完整人工复核/发布和现场未知补档的 20 分钟业务闭环仍需经办人员验收。恢复请求的费用在没有单价或账单时为未知，不写零。独立恢复验收见 `competition-independent-review.md`；评分工具口径见 `比赛评分口径.md`。


## 已知人工验收入口

涂改资料先在“材料核对 → 涂改与签章核验”判断并选择原件页。无法判断时保存草稿并挂起；取得清晰证据后用“继续人工核验”，不必重新识别。后备任务发现同版本的人工草稿会取消回写，避免草稿因后台版本更新失效。

待核验列表的“可补齐当前已知材料链”只描述已导入材料；不保证所有历史合同均已找齐。先处理这一组，再看简单材料，可以减少缺一份导致整宗暂不完整的情况。

本轮无真人签章决定，没有新增真实发布；模型读取完成和离线字段诊断不能作为入库成绩。
