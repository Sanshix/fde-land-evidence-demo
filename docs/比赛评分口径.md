# 比赛评分：实际导出、固定分母与组合收益

`scripts/score_submission.py` 只读标准答案和实际提交目录/产品导出 ZIP，不导入模型客户端，不读取或修改产品数据库，也不利用答案填补字段、改写“处理方式”。输出写到单独目录。它调用原始 `练习集/score.py`，另外完整计算五项得分，与官方显示到一位小数的结果逐项比对；不一致时停止出报告。

```sh
.venv/bin/python scripts/score_submission.py \
  --answers ../练习集/08_标准答案 \
  --submission /absolute/path/to/export.zip \
  --output runs/scoring-current
```

也支持目录，其中放 `合同要素.csv`、`宗地台账.csv`、`问题清单.csv`。提交缺文件按官方缺失处理；标准答案缺文件报错。三个 CSV 从 ZIP 根目录读取，不解压归档中的其他文件。默认评分脚本为 `../练习集/score.py`；异机可显式传 `--scorer /absolute/path/score.py`。

输出包含 `score_report.json`、原始 `official_score.txt`、逐合同与宗地状态 CSV、`字段差异.csv` 和 `评分核对.md`。JSON 记录输入 CSV 与评分脚本 SHA-256，便于比对两台机器的数据与版本。

## 指标如何读

- **提交覆盖率**：标准答案中有对应提交行的合同/宗地数。不能只凭路径或 ZIP 名称声称真人完成了发布。宗地匹配忠实采用官方算法：从提交“档案号列表”找到标准“宗地键”，不是只比较两行的“宗地键”列。
- **全量字段准确率**：固定以标准答案非空字段为分母。练习集为 731 个；缺行计错。已提交子集只统计这些提交行对应的非空应评字段，分子不借用未提交识别候选。答案为空而提交了内容，另记“意外非空”，避免悄悄改变固定分母。
- **官方字段诊断分母**：另记每字段 `official_correct` 与 `official_denominator`。官方脚本会在答案空、预测非空时计入分母，因此它与固定非空分母不是同一个指标。
- **整份准确率**：关键 12 字段必须全部正确；另报全部 15 字段全对数。字段平均准确率不能替代整份正确率。
- **错误自动放行**：只统计实际提交的自动通过行。官方把缺行也当作自动错误，单列 `official_automatic_including_missing`，不能把缺行叫作实际自动放行。
- **缺失清单**：列出所有缺少合同和宗地。重复档案号按官方最后一行计分，但发出警告，不重复增加覆盖数。

对于 50 份合同，如果已提交全部为人工复核，剩余缺失，合同得分为：

`30 / 50 × max(0, 0.5m − (50−m))`

因此 33 份得 0，34 份得 0.6，36 份得 2.4。全量且其余正确的人工复核上限为 **77.5 分**：合同 15、归集匹配 15、核算 22.5、问题清单 20、催缴对象 5。该上限不是某一真实模型运行的分数。

自动通过的计分期望为 `2p−1`，人工为 `0.5`；故 `p>75%` 是自动通过更划算的必要条件。即使验证子集零错误，也必须同时披露样本数；不能将零观察错误解释为零风险，更不能按答案挑选自动通过行。

## 用实际情景测收益

```sh
.venv/bin/python scripts/score_submission.py \
  --answers ../练习集/08_标准答案 \
  --submission /absolute/path/baseline \
  --scenario recovery=/absolute/path/recovery \
  --scenario reviewed=/absolute/path/reviewed \
  --scenario recovery+reviewed=/absolute/path/both \
  --output runs/scoring-scenarios
```

每个路径必须是已产生的独立实际导出。工具不会生成反事实 CSV，也不会把人工复核标签批量改成自动通过。基线报告位于输出根目录，各情景完整报告在 `scenario-1` 等编号目录，名称与得分映射见 `scenario_comparison.json`。

当情景名为 `A+B` 且另有 `A`、`B` 时，比较表增加：

`组合交互 = (score(A+B)−score(base)) − (score(A)−score(base)) − (score(B)−score(base))`

这个数只揭示评分截断与关联造成的非加性，不等于根因因果贡献。不得按恢复文件份数把剩余失分分成供应商、合规和模型精度百分比。

真实云识别终态、人工判断、产品发布记录和答案评分应分别留证。评测集没有标准答案时，本工具不能报告准确率或分数，仍须逐份记录处理状态并现场核验。
