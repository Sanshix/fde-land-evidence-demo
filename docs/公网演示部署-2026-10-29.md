## 启停

SSH 登录后：

```sh
cd /opt/fde-public-demo
sh manage-public.sh start
sh manage-public.sh status
sh manage-public.sh stop
```

启动脚本只管理自身 PID，不停止其他占用端口的程序；应用日志为 `logs/public-server.log`。密钥与业务数据不随重启清除。
