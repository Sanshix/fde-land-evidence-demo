## 再次运行

SSH 登录服务器后：

```sh
cd /opt/fde-deploy-test/fde-centos7-x64
sh deploy-test.sh
```

首次启动会校验文件、初始化数据库并在后台启动；再次执行不会清空数据。

```sh
sh deploy-test.sh status
sh deploy-test.sh stop
```

此脚本专供本次独立部署验收，固定本机端口并关闭识别线程；不作为已经完成公网鉴权、HTTPS、生产运行托管的证明。
