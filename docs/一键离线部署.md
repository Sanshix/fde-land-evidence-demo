# 当前 Windows 交付包（内置解释器）

本次实际生成的 `FDE-Windows-x64.zip` 使用官方 CPython 3.12.10 Windows x64 嵌入式运行时，随包提供全部依赖，不依赖系统 Python。

1. 完整解压 ZIP 到可写目录。
2. 双击 `安装.cmd`，完成后双击 `启动.cmd`；也可直接启动，首次自动初始化。
3. 浏览器默认访问 http://127.0.0.1:18765，关闭服务窗口或 Ctrl+C 停止。

默认端口占用时自动选择空闲端口，并按实际地址打开浏览器；以启动窗口打印的地址为准。显式设置 FDE_PORT 时保持指定值，冲突会报错。

无需联网安装、管理员权限或 Docker。`install.cmd` 和 `start.cmd` 是同等功能的英文文件名备用入口。源码直接位于 app、config、scripts、packaging，运行时位于 runtime，业务数据保存在 data。此包没有 fde.exe，脚本调用包内 runtime/python.exe。

云识别仍需网络及自行配置密钥；根目录 .env 可参考 .env.example。默认 providers.json 由公开的 providers.competition.json 复制，不包含开发机密钥。目标为 Windows 10/11、Server 2019/2022 x64；Windows 原生运行尚未验收。

可在 macOS、Linux 或 Windows 构建机重新生成此方案（构建机需 Python 与 pip，构建过程联网）：

```
python scripts/build_windows_bundle.py --output /absolute/new/directory
```

# 一键离线部署

适用目标：Windows 10/11、Windows Server 2019/2022 x64；Linux x86_64、glibc >= 2.35（如 Ubuntu 22.04/24.04）。不支持 ARM、Alpine/musl 或较老 glibc。以上为构建目标，须以目标机实际验收为准。

## 使用

将总交付包复制到目标机，解压后再解压对应系统的 zip 到有写权限的目录。无需 Python、pip、Docker、管理员权限或联网安装。

- Windows：双击 `安装.cmd`，完成后双击 `启动.cmd`。
- Linux：在解压目录执行 `sh 安装.sh`，再执行 `sh 启动.sh`。启动脚本会自动补上可执行权限。

也可直接运行 fde（Windows 为 fde.exe）；首次启动自动初始化数据库。安装可重复执行，不清空已有数据。启动后访问 http://127.0.0.1:18765；有桌面浏览器时自动打开，无桌面服务器执行 `./fde --no-browser`。关闭运行窗口或 Ctrl+C 停止服务。端口冲突可通过环境变量 FDE_PORT 更换端口。

程序在当前用户身份下前台运行，不注册系统服务。远程访问须由管理员设置 FDE_HOST、FDE_ALLOWED_ORIGINS、FDE_USERS_FILE，账号可用源代码中的 scripts/manage.py 创建；服务器还应配置相应网络访问规则。

## 数据与识别

`data/` 保存数据库、上传材料与业务输出；备份时先停止服务，复制整个部署目录。更新时使用新目录并迁移原 data 和自有配置，禁止覆盖正在运行的目录。

包内业务基础表及模板来自练习集，用于复现赛题；不含合同扫描件、标准答案、个人账号或开发机数据库。正式使用前将业务基础表替换为授权数据。源代码位于 `源代码/`。

安装、启动、业务管理与确定性计算无需联网。当前云 OCR/模型识别需要网络及调用方密钥，可在主程序旁创建 `.env`（变量示例见 `源代码/.env.example`）。供应商启用配置使用 `config/providers.json`，可从包内 `config/providers.*.json` 选择并复制，核对接口、模型和授权范围后再使用。不包含本地模型权重，不能宣称断网 AI 识别已交付。macOS Vision 不适用于 Windows/Linux。

## 一键打包

仓库 GitHub Actions 页面选择“一键构建 Windows 和 Linux 离线部署包”，点击 Run workflow。两个原生构建任务完成并通过冒烟测试后，下载 `FDE-Windows-Linux-离线部署包` artifact，其中含两个系统的 ZIP。下载 artifact 可能要求 GitHub 登录。

本机原生构建（联网构建机已安装 Python 3.12）：

```
python -m pip install -r requirements.in pyinstaller==6.16.0
python scripts/build_portable.py --output portable-build
python scripts/smoke_portable.py portable-build
```

构建过程联网，目标机安装不联网。不能在 macOS 生成 Windows/Linux 原生可执行文件。依赖、Python 解释器与业务源码随包提供；BUILD_MANIFEST.json 记录文件 SHA-256。构建与安装检查不等于干净虚拟机验收，交付前应分别在无 Python、断网的 Windows 与 Linux 虚拟机验证安装、重启、材料导入、租金计算及备份恢复。
