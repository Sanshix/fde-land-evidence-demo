# 确定性解析：三批离线回放，最终隔离版本 v5

方案合理，核心边界已实现并测试：结构唯一可判定的自动解析；解析未决保留证据并补读，不靠多数投票或答案填值。**本轮交付为隔离候选，尚未达到零退化推广门槛。** 已消除上一版 LX-011 坐落的新增事实性错误唯一值；最终严格评分净增1个正确字段，但有1个原正确字段转为补读，不能用总分提高抵消。

## 本轮实现

1. 原响应永久保留；在标签、单位、值分离后做类型准入。多数字、未知公式、非法日期不进入业务候选。标识符保持字符串与前导零，缺失不补0。
2. 局部处理完整承租人角色标签、同一行证件号/电话边界、明确原新合同号、合法同日重复日期与明确租期区间；保留企业名括号，不全局替换姓名/编号字符。
3. 同源按单元格、完整标签、受支持句式组织提取；同一位置不重复制造证据，不同位置原文仍保留。完整片段定位取代前六字符匹配，不能定位时不伪造位置。
4. 新增字段裁决层：`candidate_observations` 保存类型有效的观察；`candidates` 只提供已通过该层的待业务复核值。状态独立为 `unique_observed / conflict / needs_read / missing`。一个有效值同时存在未读清的来源时，业务值被暂扣，观察及拒绝原因不删除。
5. 未勾选菜单、单位价格与无法读清的勾选内容分别处理。v4把这些都归为同一种例外过宽，已收窄：完整空白选项菜单不主张选择；带勾但文字不明仍需补读。未做“地→随”或“xx→××”猜测。

原值、原文、响应ID、响应行/单元格位置、规则版本、拒绝原因均随证据保存。响应位置不是人核原图坐标。业务材料完整性保持 `not_assessed`，发布资格保持 `requires_human_confirmation`；没有修改人工发布规则、确认数据或产品数据库。

## 批次与严格评分

每次只回放5份已保存模型响应，先落盘和审查，再进入下一批。第二、三批先后因发现问题参与修复，最终**三批均为开发回归集，无独立验证集**。最新v5仅按顺序重跑已有三批，第一批发生退化后保持隔离，第二、三批仅检查已有范围的影响；没有第四批、没有全量扫描、新云调用为0。

历史报告731字段来自50份档案，分布为正确461、错误唯一29、冲突204、缺失37。本轮选中15份、216个标准答案非空的“文档×语义字段”；基线使用任务开始时冻结的当前解析代码，对相同历史响应重新解析。**不能把731字段历史分数直接与本轮216字段比较。** 每批新旧响应哈希、答案哈希一致，评分器不变，分母不按候选数计。

## 关键变化与仍未解决的边界

- **LX-002合同编号：** 完整片段及原新角色定位修正后，当前2025/007与原合同2021/008不再混淆。新增1个严格评分错误仅因 `(2025)` 对 `〔2025〕` 的年份括号表现不同。补充审查标注语法等价，原评分错误仍如实计数；没有改答案、评分器或字符硬编码。
- **LX-009起止日期：** 明确租赁期限给出2010-07-01至2015-06-30，新增2个正确字段。
- **LX-001、LX-011、LX-013承租人：** 公式残留不是可靠姓名；清晰候选仍留在观察中，最终字段需补读，不能称新增正确唯一值。
- **LX-007面积：** 原图有569.46划去及579.46替换。仅剩一个有效候选不代表涂改已解决；现为补读，原双值及清晰候选均保留。
- **LX-011坐落：** 上一版因拒绝公式后留下`xx镇北山路37号`，形成新增错误唯一值。现为补读；没有把`xx`猜改成`××`。原图只读检查与冻结回放分开，未把视觉判断写成解析结果。
- **LX-004计租方式：** 一份响应为`☐固定 ☑随基准地价调整`，另一份为`□固定 √地基准地价调整`。v4把后者误归空白菜单；v5将其保留为未决，原评分从正确变缺失。只读原图可见第二选项勾选，但这属于图像证据，不是对冻结字符串的确定性修复。未写成特殊规则，也未覆盖业务数据。此项阻断零退化验收。
