01 · 业务闭环 (15秒速读)

一期只做三件事：建准台账 → 算准欠款 → 到点催缴报税

遵循奥卡姆剃刀：砍掉跨部门接口，用文件导入导出解决
① 变废为宝：一宗一档库 替人翻档案柜

小白视角：把扫描合同、登记表、缴费单喂给系统，自动按“同一块地”串成完整档案，手写涂改、缺页自动挑出来让人看。

🔧 技术：Layout-OCR + 三源主键对齐 + 状态强制[待确认]
② 铁面算盘：代码规则算费 替财务算分段账

小白视角：租金按年限分段涨价，程序1秒算出每年应收多少、欠多少。资料说不清的，先按对老百姓最有利（少交钱）暂算并挂账。

🔧 技术：确定性规则引擎 + 双算法差额快照 + 改规则历史重算
③ 到点叫醒：提醒与推送 替人盯着到期日

小白视角：像手机日历一样提醒经办人“哪块地快到期、谁欠钱”；一键生成催缴单发短信给产权人，一键导出税务局要的表格。

🔧 技术：分级日历触发器 + 制式模板渲染 + 税务离线推送快照

04 · 架构与流程 (40秒速读)

左看「技术栈怎么防错」，右看「经办人怎么干活」

对应评分：现场补档(40分) + 部署运行(25分) + 流程测算(20分)
左栏：离线技术栈（4层解耦） 政务网断网可用
1. 交互层：双屏核验 + 仿日历看板 React/Vue + PDF.js
左屏扫描件红框坐标定位，右屏表单修改留痕；日历红黄绿三级预警。
2. 规则与事务层（核心护城河） 0 AI推算 · 事务回滚
• 算费引擎：纯代码计算年期分段与地价浮动，存疑自动双算比差。
• 防重与撤回：文件 SHA-256 幂等防重；批次 ID 绑定，导错一键级联回滚。
3. AI 感知网关层（支持现场热切换） Cloud API ⇄ 本地 Qwen2.5-VL
统一 Adapter 抽象接口，只做 OCR、要素抽取、三源冲突比对；输出一律标 [待确认]。
4. 存储与离线交付底座 PostgreSQL/SQLite + Docker
单机离线安装包（不连外网下载组件），内置一键备份、恢复与全链路审计日志。
✔ 现场可秒切开源模型完成补档 ✔ 满足等保与政务内网隔离
右栏：4 步极简 SOP 与 3,000 份算账 非技术人员可操作
Step 1. 拖入材料 → 自动防重与归宗
AI 识别文字要素，自动归入已有宗地或新建宗地。
AI · 15秒/份
Step 2. 三源比对 → 70% 常规卷批量过
合同+登记+缴费一致的(约2,100份)，人工抽检后批量确认。
人 · 45秒/份
Step 3. 异常拦截 → 30% 冲突卷双屏精核
涂改/缺页/面积不符(约900份)对照红框改；说不清的挂入《待确认清单》按低值暂算。
人 · 3.5分/份
Step 4. 规则算账 → 发催缴短信 / 导税务单
程序算出欠款，人工点确认后发短信、导出税务文件（导错一键撤回）。
代码 · 1秒
📐 3,000 份实测工时公式（共 90 小时 = 2人 × 7.5天）：
2,100份×45秒 (26.25h) + 900份×3.5分 (52.5h) + 15%质检缓冲 (11.25h) = 90工时
