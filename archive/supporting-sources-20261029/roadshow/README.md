# 国有土地租赁智能管理系统

八页精简路演，默认正文每页 83–169 个非空白字符，合计 1,034 个，按每页 15–30 秒、全场 3 分钟设计。实际理解时间仍与观众背景有关。基于本地赛题、当前 demo 源码与留存验收记录编写；不虚构模型效果或生产安全能力。

## 最快打开

直接双击 `index.html`。同目录 `style.css`、`model.js`、`app.js` 必须保留。无需 npm install，不联网、不下载字体、不调用模型。

本地 HTTP 方式（需要 Python 3）：

```sh
cd '/Users/sanshi/Code/FDE/土地租赁合同管理/roadshow'
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 http://127.0.0.1:4173 。也可运行 `npm start`（仍调用 Python）。Ctrl+C 停止。

若 4173 被占用，改为 4174 并打开相应端口。只监听本机，不作为生产 Web 服务。

## 皮肤

右上角“皮肤”选择：政务蓝（默认，蓝底色调与少量红色强调）、深蓝投屏（深色背景与高对比文字）、蓝白简报（白底深蓝，适合正式汇报）。选择保存在本机浏览器；存储不可用时仍可切换，但不跨刷新保留。

## 操作

- 左侧章节或底部箭头翻页；键盘 ←/→、PageUp/PageDown 同样可用。
- 表单内方向键保持原生操作。Tab 遍历；Enter 激活；Esc 关闭详情。
- “讲解提示”显示逐页讲稿；“本页依据”显示来源、章节及结论边界。
- 全屏按钮使用浏览器 Fullscreen API；不支持时提供菜单操作提示。
- 核心演示支持正常续期、口径存疑、模型失败转人工、新宗地建档；可确认、重复导入、撤回、重导和下载操作记录。
- 切换场景/重置/刷新会清空示例状态。当前页面状态与操作记录只在内存中保存。
- 电脑优先，已检查 1920×1080、1366×768、390×844；长内容允许滚动。

## 两分钟演示路径

1. 第 04 页点击“操作补档流程”，导入正常续期示例；直接确认，展示未复核门禁。
2. 勾选归宗与三项核验，填写“核对示例材料第1页及归宗标识”，确认；欠缴 600→900 元。
3. 再次导入，展示重复拦截与有效贡献仍为 1。
4. 预览催缴草稿，说明逐年度付款分配/缴纳地点等仍需完善，不可发送。
5. 关闭草稿并撤回：欠缴恢复 600 元，草稿按钮禁用。
6. 重导，说明不能复用旧的人工确认。
7. 切换模型失败：导入→转人工→填写金额→重新复核。

为控制阅读负担，已移除常驻评分图表、人力测算器、装饰地图与英文页眉。技术说明与来源通过点击查看；完整操作位于第 04 页的展开入口。

## 文件

- `index.html`：入口与可访问导航。
- `style.css`：响应式视觉系统。
- `app.js`：八页内容、详情、键盘与交互。
- `model.js`：独立教学状态机。
- `tests/workflow.test.cjs`：可重复运行的状态机回归。
- `设计方案.md`：信息架构、流程、视觉规范、线框与选型。
- `验收结果.md`：本次逐项验收及未验证范围。
- `evidence/sources.json`：本次读取来源的路径与 SHA-256。
